## 建议的阅读路径

**只想用起来** → `README.md` 第 3、4 节，看完就能跑。

**要改代码** → `CODE_MAP.md` 第 6 节「改需求时该动哪些文件」→ 定位到文件 → 回头查 `ARCHITECTURE.md` 理解约束。

**要排查"数据丢了 / 响应少一截"** → `ARCHITECTURE.md` 第 5 节 → 对照 `core/net/TcpConnection.cpp` 与 `ConnectionReaper.cpp`。

**要换语言重写客户端** → `PROTOCOL.md` 全文 + `core/protocol/Protocol.h`。

## 文档维护约定

- 目录、文件名、控制命令、配置字段一旦变动，**同一次提交里同步更新文档**，不留过期路径。
- 代码里能说清的事不写进文档（避免两份真相）；文档只写**取舍和约束**。
- 文档中的路径一律相对仓库根目录，不用绝对路径。
